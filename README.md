### [Codex Local Subagent](https://github.com/Ossi-1337/codex-local-subagent)

**Delegate broad repository reading to local LLMs while keeping Codex in control.**

Codex Local Subagent provides a read-only MCP server and skill for exploring large
codebases with local models. It returns compact file-and-line evidence while Codex

### [Actio](https://github.com/Ossi-1337/actio)

**Run GitHub Actions-style workflows locally with fast feedback and full control.**

Actio is a local-first workflow runner for YAML pipelines. It executes Docker-backed
jobs, stores runs, logs, caches, and artifacts locally, and provides both a CLI and a
lightweight loopback web interface.
